# Pitch vidéo

Ajoutez votre courte présentation vidéo dans ce dossier avec le nom exact `pitch.mp4` (MP4, idéalement H.264/AAC). Le lecteur apparaîtra automatiquement sur le site après le déploiement GitHub Pages. Sans fichier, le site affiche « bientôt disponible ».

La photo `tipe-prototype.jpg` illustre le projet TIPE.
